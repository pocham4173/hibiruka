# ✨ AIで文章を作成

記録からAIで文章を作る。**無料**で動かす。

| 種類（mode） | どこで | 何を作る |
|---|---|---|
| diary | 記録画面「✨ AIで文章を作成」 | 80〜120文字の日記風の文章 |
| short | 同じ枠の「ひとこと」 | 15〜30文字のひとこと |
| sns | 同じ枠の「SNS用」／SNS投稿のX画面 | 投稿文＋ハッシュタグ（最後に #ヒビルカ） |
| title | 「題名」の下「✨ 題名の案をAIに聞く」 | 題名の案3つ |
| month | 思い出タブ「✨ AIでふりかえり」 | 今月／先月の思い出から150〜250文字のまとめ |

## しくみ
1. アプリ（GitHub Pages）が Firebase のIDトークンを付けて `https://hibiruka-line.okm-co.workers.dev/ai/memory-text` に送る。
2. Worker（`line-worker/ai.mjs`）がトークンの署名・プロジェクト・期限を確認する（Googleの公開鍵）。
3. 1人1日20回、全体で1日400回まで（`aiUsage` に回数を保存、アプリからは読めない）。
4. Cloudflare Workers AI（`@cf/google/gemma-4-26b-a4b-it`、無料プランで使えるモデル）に、指示文（`SYSTEM_PROMPT`）と記録を `<記録>` で囲んで送る。
5. 返ってきた文章をアプリに表示。「メモに入れる」「もう一度作る」「やめる」、入れたあとは「元に戻す」。

APIキーは不要（Worker の `AI` バインディングを使う）。

## 費用
Workers 無料プランには 1日10,000 Neurons の無料枠がある。無料プランでは枠を超えると**エラーになるだけで請求されない**。
1回あたり約12 Neurons（入力約700・出力約200トークン）なので、無料枠で1日800回ほど。上限400回/日でもおさまる（ふりかえりは1回約30 Neurons）。

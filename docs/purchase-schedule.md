# 買い物・定期購入（2026-10-16）

## 今回の範囲

「予定・記録」→「買い物・定期購入」から商品名、お届け予定日、任意の商品リンクを登録。
定期購入を選んだ場合だけ、日・週・月単位の間隔を表示する。
金額（見込み）・変更期限・メモは折りたたみ内の任意項目。

お届け予定を既存カレンダーに表示する。日付を過ぎても受け取り済みにはしない。
「受け取った・次回へ」で今回を思い出として残し、次回1件を同じトランザクションで作成。
月末は元の日にちを保持（1/31 → 2/28 → 3/31）。日付を手動変更したら基準日も更新。
未来の予定は1回分のみ。配送実績・金額の確定・店舗側の注文や解約は同期しない。

管理停止中はカレンダーから外し、買い物一覧には残す。再開時は日付を確認して保存。
購入済みの履歴を再び予定には変えない。新規登録する。

## 通知

既存のLINE・アプリ通知の予約画面を使う。送信先は本人が選ぶ。
期限がある場合は、変更期限前日・当日の9時も候補に出す。
通知は各回ごとの明示予約。次回予定へ宛先・予約・送信結果・変更期限をコピーしない。
停止・編集・受け取り処理は、未完了の通知があれば取り消し完了までブロックする。
通知画面を開いた後で停止・編集された場合は、古い画面からの通知予約を拒否。
既存Worker、無料枠、課金設定には変更なし。

## 商品リンクの取り込み

- コピーしたリンクを登録画面へ貼り付ける方法は全端末共通。
- Android等の対応環境はmanifestのshare_targetでURL・テキスト・題名を受け取る。
- iPhoneは手動で初回ショートカット設定が必要（アプリ内に設定説明あり）。
  共有入力をURLエンコードし、受け取り先 `https://pocham4173.github.io/hibiruka/index/index/#purchase=` の末尾へ付け、「URLを開く」。
- 取り込みは未保存の入力画面を開くだけ。商品名と日付を本人が確認して保存。
- 初回ログインへの移動中はURLのみをsessionStorageで30分まで保持。
- iPhoneのSafariとホーム画面アプリが別アカウントなら、同じメールで復旧してから利用する。
- 写真、価格、Amazonアカウント、購入履歴は取得しない。

## 保存と確認

既存のevents / personalEventsを使用し、既存の所有者・共有範囲を維持。
購入専用の新コレクションや権限の拡張は行わない。個人の記録はownerUidで限定。
以前の共有モードには共有範囲を画面に表示。CSVには商品情報も含める。
編集はrevisionで競合検出。受け取りの再実行で次回予定を重複作成しない。

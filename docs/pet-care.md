# うちの子（初期版）

状態：実装・隔離検査済み。2026年10月15日にGitHubへの保存とアプリへの公開が承認された。保存先の権限・Workerの反映を確認してから画面を公開する。実機未確認。

## 範囲

1. 本人専用のペットプロフィール、写真、誕生日・お迎え日、経過日数。
2. 既存の予定・思い出への複数ペットの紐付けと、お世話の種類・体重の記録。
3. 訂正、およびペットの記録を写真ごと削除・復元する操作。

設定の小さな「うちの子」から利用する。主要タブは追加しない。プロフィールが1件以上ある場合だけ、予定画面の小さな入口と、記録入力の折りたたみ欄を表示する。旧共有モードには個人のペット情報を混ぜない。

## 操作

「設定」→「うちの子」→「うちの子を登録」。プロフィールは任意の写真と名前で登録する。誕生日・お迎え日は空欄や推定も可能。当日を0日とする日付差を表示し、端末の今日の日付で計算する。未来・存在しない日付・逆転した誕生日とお迎え日は保存を拒否する。

「みんな」「未分類」「各ペット」を切り替える。未分類は、まだペットを選んでいない本人の既存記録を表示する。編集の「うちの子を選ぶ」で追加・変更する。名前の変更で記録が切れないよう、名前でなく固定IDで関連付ける。

「記録を残す」「予定を入れる」は既存の記録入力を使い、写真・日記も同じ記録に保存する。ペットの予定も既存カレンダーに1件だけ表示する。予定は日が過ぎても実施済みにしない。体重は測定日・前回比を表示し、1匹ずつの数値を保存する。

記録名を押すと詳細を表示し、既存の削除ボタンから削除できる。ペットに紐付いた記録の削除は復元できる非表示処理。「うちの子」内の「削除した記録を戻す」から復元する。写真・通知台帳等を作り直さず保持する。未完了のお知らせ予約がある記録は、予約を取り消してから削除する。非表示の記録はアプリの一覧・振り返りとLINEの今日/振り返りから除外する。

## 保存・安全性

- プロフィール：`personalPets`、本人UIDで問い合わせ・権限制限。写真は240px正方形JPEG、100KB以下のデータURL。原寸画像・位置情報をプロフィールに保存しない。
- 記録：既存 `personalEvents` に `petIds` / `petCareType` / `petWeightKg` / `petHidden` を追加。写真は既存 `personalPhotos` を使う。
- プロフィールの保存はトランザクションで、別端末の変更とアカウント切り替えを検査。応答不明後の再試行は同じIDを使う。
- 削除・復元もトランザクション。削除時は最新の通知予約を検査。復元は非表示フラグだけ変更し、他の内容を上書きしない。
- アカウントの全データ削除にはプロフィールと非表示の記録・写真も含まれる。
- 家族共有、診断、支出管理は範囲外。写真にあったユーザーのペットは勝手に本番登録しない。

# 個人別利用機能

## 変更すること

- 初めての人は「はじめる」で自分専用の予定・思い出を作る。
- 既存の利用者は従来の記録・写真・LINE送信先を引き続き使う。既存レコードの移動や削除はしない。
- 新規利用者は personalConfig / personalEvents / personalPhotos / personalFriends に保存し、所有者の Firebase UID で読み書きを制限する。
- 設定でメールとパスワードを匿名アカウントにリンクする。UIDを変更せず、別のブラウザ・端末からログインできる。
- メール未登録の状態では、ブラウザのデータ消去や機種変更で記録に戻れなくなることがある旨を表示する。
- 招待リンクに scope=personal を付ける。既存の招待リンクは従来通り扱う。
- 招待承認で利用者の既存ログインを解除しない。
- LINE送信処理は従来の予約に加え、個人別予約を取得する。所有者が一致する承認済み送信先だけを使う。

## 別課題

GitHub Actions の定期実行が大幅に遅れる問題はこの変更では解消しない。LINE通知の定刻実行は別の送信基盤への変更が必要。

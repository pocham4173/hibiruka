# 地元のお店の「見せるだけクーポン」の増やし方

`data/coupons.json` の `"coupons": [ ]` の中に、お店ごとに1つずつ書きます。
GitHubでこのファイルを開いて、えんぴつ（編集）ボタンから書き足して「Commit changes」を押すと、数分でアプリに出ます。

```json
{
  "coupons": [
    {
      "shop": "わんこカフェ ひだまり",
      "benefit": "ワンちゃんおやつ1個サービス",
      "icon": "🐶",
      "until": "2026-12-31",
      "conditions": "1グループ1回まで。ほかの割引とは一緒に使えません。",
      "address": "長野県上田市〇〇1-2-3",
      "lat": 36.4019,
      "lng": 138.2493,
      "url": "https://example.com"
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| shop | ○ | お店の名前 |
| benefit | ○ | 特典（大きく表示されます） |
| icon |  | 絵文字1つ（なければ 🎁） |
| from |  | この日から表示（"2026-11-01" の形） |
| until |  | この日まで表示。過ぎると自動で消えます |
| conditions |  | 利用条件 |
| address |  | 住所 |
| lat, lng |  | 地図と「近い順」に使う位置 |
| url |  | お店のページ（https から始まるもの） |
| hidden |  | true にすると一時的に隠せます |

- 2つ以上書くときは、`}` と `{` の間に `,`（カンマ）を入れます。
- クーポン画面には、いまの日時が秒まで動いて表示されます（前に撮ったスクリーンショットではない目印）。
- お店とは「どの特典を」「いつまで」「1人何回まで」を先に決めておいてください。

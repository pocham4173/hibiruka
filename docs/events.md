# 地元のイベントの増やし方

`data/events.json` の `"events": [ ]` の中に、イベントごとに1つずつ書きます。
GitHubでこのファイルを開き、えんぴつ（編集）ボタンで書き足して「Commit changes」を押すと、数分でアプリの「探す」→「🎪 イベント」に出ます。

```json
{
  "events": [
    {
      "title": "上田わっしょい",
      "from": "2026-07-25",
      "to": "2026-07-25",
      "time": "17:00〜21:00",
      "place": "上田市中心市街地",
      "pref": "長野県",
      "city": "上田市",
      "lat": 36.4019,
      "lng": 138.2493,
      "icon": "🏮",
      "url": "https://example.com",
      "memo": "雨天決行"
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| title | ○ | イベントの名前 |
| from | ○ | 始まる日（"2026-07-25" の形） |
| to |  | 終わる日（1日だけなら書かなくてOK） |
| time |  | 時間 |
| place |  | 会場 |
| pref, city |  | 都道府県と市町村（「県・市町村で選ぶ」で絞り込むときに使います） |
| lat, lng |  | 位置（近い順と「予定に追加」に使います） |
| icon |  | 絵文字1つ（なければ 🎪） |
| url |  | 詳しいページ（https から始まるもの） |
| memo |  | ひとこと |

- 終わった日を過ぎたイベントは自動で出なくなります。
- 2つ以上書くときは、`}` と `{` の間に `,`（カンマ）を入れます。
